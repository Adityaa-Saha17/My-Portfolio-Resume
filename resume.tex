\textbf{32-bit RISC-V CPU Simulator} \hfill C/C++ \sep \href{https://github.com/Adityaa-Saha17/32-bit-RISC-V-CPU-Simulator.git}{GitHub} \\
\begin{itemize}
    \item Implemented a cycle-accurate RV32I processor simulator with a 5-stage pipeline (IF, ID, EX, MEM, WB) and a two-pass assembler resolving labels and forward references.
    \item Added a hazard detection unit with EX/MEM and MEM/WB forwarding paths, load-use interlock stalls, and control-hazard flushing on taken branches.
    \item Instrumented the pipeline with branch prediction, per-stage tracing, and CPI/stall/flush counters exported as JSON for offline analysis.
\end{itemize}

\textbf{LSM Tree Key-Value Store} \hfill C++ \sep \href{https://github.com/Adityaa-Saha17/Log-Structured-Merge-Tree}{GitHub} \\
\begin{itemize}
    \item Built a disk-based key-value store on a Log-Structured Merge Tree, flushing an in-memory MemTable to immutable block-based SSTables with a sparse index for binary-searched lookups.
    \item Implemented leveled compaction to bound read amplification, merge overlapping key ranges, and reclaim space from tombstoned and overwritten keys.
    \item Integrated a write-ahead log with replay-on-startup crash recovery and CRC32 checksums to detect corruption on every read path.
\end{itemize}

\textbf{DNS Server Implementation} \hfill C++ \sep \href{https://github.com/Adityaa-Saha17/DNS-Implementation}{GitHub} \\
\begin{itemize}
    \item Built a multithreaded DNS server handling RFC 1035 wire-format parsing and serialization over both UDP and TCP, backed by a fixed-size thread pool.

    \item Added per-client rate limiting and domain blocklists, with rotating logs and an HTTP \texttt{/metrics} endpoint reporting query volume, cache hit ratio, and error rates.
